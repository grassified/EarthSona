# EarthSona coding-agent guide

Start with [README.md](README.md), [CONTRIBUTING.md](CONTRIBUTING.md), and the current Git status. Branch from current `main` and keep one purpose per PR. Use the [PR template](.github/pull_request_template.md) and the [bug report](.github/ISSUE_TEMPLATE/bug_report.yml) or [feature request](.github/ISSUE_TEMPLATE/feature_request.yml) form when applicable. Use Node.js 22.12 or later in the Node 22 line and run `npm ci`, `npm test`, and `npm run build`. These are the CI commands. The build runs `npm run check` before Vite. For a failed CI step, reproduce its command on Node 22 after `npm ci` and inspect the failing output. Smoke-test the production output with `npm run preview -- --host 127.0.0.1`.

- `src/main.ts` owns shared UI state, scan and transport, preferences, and the playback session. `src/style.css` and `src/redesign.css` hold layout and themes, with accent logic in `src/appearance.ts`.
- Keep live playback under the shared session in `src/audio.ts`. Stop and Escape must cancel queued notes, scheduled Flow, and pending scrub or resume work. Switching datasets or replacing playback must invalidate stale work. Player and Lab share transport and speed. Studio preview uses the same playback session, and Studio download uses the separate renderer in `src/studio-export.ts`.
- Preserve sustained Ambient Flow across sparse scan samples and wraparound. Keep the scheduling horizon bounded and retain reusable voices in `src/flow-audio.ts` and keep phrasing in `src/arrangement.ts`. Check that Stop clears sound and that waking from a stalled timer cannot replay a backlog.
- `src/datasets.ts` owns imagery, bounds, presets, classifier, and credits. `src/sampling.ts` owns patch and scan-column rules. Keep globe picking and the visible markers aligned to normalized source pixels through `src/globe.ts` and `src/projection.ts`. Retain the 2D option, automatic globe fallback, and 2D-only handling for unaligned stills.
- Keep runtime assets under `public/` and document their provenance in [docs/DATASETS.md](docs/DATASETS.md). Keep code licensing and asset credits separate. After install, core playback and export must work over a local HTTP server with external requests blocked.
- Keep English and Turkish user-facing strings, labels, help, and dataset descriptions in sync. Check `src/i18n.ts`, `src/datasets.ts`, `src/studio.ts`, and the launch messages in `index.html`. Test both languages at narrow and wide viewports.
- Reuse existing modules and state. `src/studio.ts` renders the editor and `src/composition.ts` owns the beat grid used by preview and export. `tests/` covers composition, Flow scheduling, projection, and sampling. Keep changes independently reviewable.
- For animation, audio, and asset changes, compare before and after under the same conditions. Check for duplicate render loops, growing audio queues, and extra asset loads. Preserve on-demand dataset loading and the dynamic Studio exporter import. Report pending device, screen-reader, and listening checks explicitly.
